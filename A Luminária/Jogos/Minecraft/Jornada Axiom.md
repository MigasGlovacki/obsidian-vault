# Jornada Axiom — Construção Criativa

> Trilha de treino pra desenvolver construção no Minecraft usando o Axiom (mod do Moulberry), começando pequeno até cidades inteiras.
> A Monika é a mentora da jornada: planeja, acompanha e registra o progresso.

## O que é o Axiom

- Mod de edição de mundo para o Minecraft (Fabric) — a evolução moderna do WorldEdit, com interface de software 3D.
- Dois modos: **Builder Mode** (simples, pra começar) e **Editor Mode** (ferramentas profundas: seleção, brushes, sculpting, copiar/espelhar).
- Fontes: [Documentação oficial](https://axiomdocs.moulberry.com/) · [Modrinth](https://modrinth.com/project/N6n5dqoA)

## Regras da jornada

- Uma fase por vez, sem pressa.
- Cada fase tem objetivo concreto + habilidade treinada.
- Só avançamos quando a fase está de pé (e registrada aqui).
- Construção é prática, não talento.

## Atalhos essenciais

- **Right Shift** — abre/fecha o Editor Mode
- **Left Alt** — menu de contexto / Builder Tools (slot 10 + scroll)
- Ctrl+C / Ctrl+V / Ctrl+X — copiar, colar, cortar
- Ctrl+Z / Ctrl+Y — desfazer / refazer
- Ctrl+R / Ctrl+F — rotacionar / espelhar
- Delete — apagar seleção
- `/whynoaxiom` — se o item do slot 10 não aparecer
