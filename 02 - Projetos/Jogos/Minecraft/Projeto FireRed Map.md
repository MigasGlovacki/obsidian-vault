# Projeto FireRed Map — Recriar Kanto no Minecraft

> Projeto futuro pra testar as habilidades da [[Jornada Axiom]]: recriar o mapa de Pokémon Fire Red do zero no criativo, usando o mod Axiom. Feito à mão, sem baixar mapa pronto — o processo é o prêmio.

## Status

- **Estado:** projeto futuro ⏳ (aguardando naturalização com o Axiom)
- **Jornada relacionada:** [[Jornada Axiom]]
- **Contexto:** FireRed em andamento na Luminária (FRLG+) — as duas jornadas se encontram.

## Regras do projeto

- **Escala:** 2 blocos = 1 tile do jogo (casa padrão ~5x4 tiles vira 10x8 blocos — a "casa caixa" da Fase 1!)
- **Blueprint base das casas:** o modelo com mini torre no canto (em experimentação na Jornada)
- Cada cidade/rota é uma fase; nenhuma peça é difícil sozinha — a soma é o projeto.

## Fases do mapa

- [ ] **Pallet Town** — 3 casinhas + laboratório do Professor Oak (blueprint repetido com variações)
- [ ] **Rota 1** — caminho de terra, grama alta dos lados, árvores
- [ ] **Viridian City** — primeiro salto: centro Pokémon, loja, mais prédios
- [ ] **Floresta de Viridian** — corredor de árvores com trilha sinuosa (Path + escadas)
- [ ] **Pewter City e além** — repetir o padrão com variações até o resto de Kanto

## Kit de ferramentas (Axiom)

- **Copy/Paste** — casas repetidas com variações
- **Path** — caminhos e trilhas (com "Use Stairs and Slabs")
- **Elevação/Nivelar** — terreno das rotas e cidades
- **Fill** — campos de grama alta
- **Symmetry (Ctrl+F / Ctrl+R)** — prédios simétricos (laboratório, centros Pokémon)
