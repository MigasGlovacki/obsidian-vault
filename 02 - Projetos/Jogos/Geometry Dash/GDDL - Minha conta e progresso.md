## Acesso

A consulta é via API do próprio site (`https://gdladder.com/api/...`), com a minha **API key pessoal** (bolso da conta → Developer settings). Só a gente usa essa chave — ela dá controle total da conta, então não vai para fonte externa nenhuma.
